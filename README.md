## Base44 Credits Explained

Base44 runs on two separate credit types — understanding them before you buy saves money:

### Message Credits
Used when **you** prompt the AI to build or modify your app. Every prompt — "add a login page", "change the button color", "fix this bug" — costs message credits. Iterating on a feature costs credits each time. Complex prompts may use more than simple ones.

### Integration Credits
Used when **your app's users** trigger actions that involve integrations: LLM calls, file uploads, image generation, email sends, SMS, database queries. Each integration request costs 1 credit regardless of type.

**The key thing to know:** On any plan, if you hit your monthly credit limit — both building and integration activity stop until your next billing cycle. You cannot buy top-up credits separately; you'd need to upgrade plans.
